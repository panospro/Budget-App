# 💰 Budget App

A full-featured personal finance app to track expenses, manage savings goals, plan debt repayment, and monitor investments.  
Built with React, Node.js, and MongoDB — designed to help users take control of their financial life.

---

## 🎯 Key Features

### ✅ Core Modules

- **🧾 Budgeting**: Add, view, and manage your daily expenses
- **💵 Savings**: Track savings, visualize progress, and set monthly goals
- **📉 Debts**: Add debts and simulate repayment strategies:
  - Avalanche (by interest rate)
  - Snowball (by smallest balance)
  - Tsunami (by stress level)
- **📈 Investments** *(placeholder)*: Track investments and portfolio allocations (WIP)
- **🔐 Auth**: Secure login/signup system using token-based auth
